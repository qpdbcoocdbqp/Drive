# Persistent Memory Index

A directory of all long-term memory for the `cmemo` project.

Summary of the 7-layer defensive pyramid for memory management.
Contains: Layer definitions, component mappings, and transition rules.

Chronological log of major architectural changes, starting from the original source.
Contains: Commit hashes, rationale for changes, and verification results.
